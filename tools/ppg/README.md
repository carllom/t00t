# PPG

This is a placeholder for a document kept on another device. In its essence, it provides resources on PPG Wave hardware and descriptions on how to interpret and extract them.
The contents of these folders are .gitignored out of the main repo in order to avoid any licensing difficulties.

There is a zip file containing the PPG wave rom `PPG Wave 2.3 version 6.zip`

There are cassette dumps containing factory settings in the `cassettes` folder.

There has already been written a tool to extract the information on the cassette dumps: `https://sourceforge.net/projects/ppgwavecass/`

More general PPG info at:

- `https://www.hermannseib.com/english/synths/ppg/default.htm`
- `https://ppg.synth.net/`
- `https://www.presetpatch.com/articles/ppg-wavetable-list`
